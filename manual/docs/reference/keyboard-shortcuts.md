# Keyboard shortcuts

On macOS, use **⌘ Cmd** wherever **Ctrl** is written. In the app, **F1** (Help → Keyboard Shortcuts) shows the most important shortcuts, and menus show them next to each entry.

## Files and editing

| Shortcut | Action |
|---|---|
| Ctrl+N | New project (new tab) |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+I | Import (images, SVG, DXF, PDF, AI, 3D models); files can also be dragged onto the workspace or pasted with Ctrl+V |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste |
| Ctrl+D | Duplicate |
| Delete | Delete |
| Ctrl+A | Select all |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous project tab |
| Page Up / Page Down | Previous / next page |

## Tools

| Shortcut | Action |
|---|---|
| Esc | Select tool / clear selection |
| Ctrl+L | Draw lines |
| Ctrl+R | Rectangle |
| Ctrl+E | Ellipse |
| Ctrl+T | Text |
| Ctrl+` | Edit nodes |
| Ctrl+K | Trim shapes |
| Alt+T | Trace image |
| Alt+P | Preview with time estimate |

## Arranging

| Shortcut | Action |
|---|---|
| Arrow keys | Move by 1 mm (Shift 10 mm, Alt 0.1 mm) |
| `.` and `,` | Rotate by 90° |
| Ctrl+G / Ctrl+U | Group / ungroup |
| Ctrl+Shift+H / Ctrl+Shift+V | Mirror horizontally / vertically |
| L, R, T, B | Align left, right, top, bottom (several objects selected) |
| C, E | Align centres horizontally, vertically |
| Alt++ / Alt+- / Alt+* | Union / subtract / intersect |
| Alt+J | Join paths |
| Alt+B | Break apart |
| Ctrl+Shift+C | Convert to path |
| Ctrl+Shift+A | Grid array |

## Node editing

| Shortcut | Action |
|---|---|
| D or Delete | Delete node |
| I | Insert node |
| L / C | Make segment a line / curve |
| E / S | Make node a corner / smooth |
| B | Break the path at the node |
| T | Trim the edge back to the intersections |

## View and mouse

| Shortcut | Action |
|---|---|
| Mouse wheel | Zoom |
| Space + drag, middle mouse button | Pan the view |
| Ctrl+0 | Zoom to page |
| Alt+W | Wireframe / filled |
| Click on the selection | Switch between scaling and rotating |
| Shift while scaling | Switch between proportional and free scaling |
| Ctrl while scaling | Scale from the centre |
| Shift / Ctrl while rotating | Rotate in 15° / 5° steps |
| Ctrl while dragging | Invert snapping temporarily |
| Alt while dragging | Snap more strongly and show alignment guides on other objects |
| Drag out of a ruler | Create a guide |
