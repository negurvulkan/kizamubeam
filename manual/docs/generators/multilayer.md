# Multi-layer work

**Multi-layer work** (**Toolbox → 3D slot-together models**) turns shapes you designed yourself into a stacked piece: a shadow box, a layered landscape, a relief or a sign with several levels. Unlike the [layered model](models-3d.md), the layers come from your own drawing, not from a 3D file.

## Creating one

1. Draw each layer as a closed shape or a group (for example a frame, mountains, trees, the sky).
2. Select them all and choose **Multi-layer work** in the Toolbox.
3. The dialog lists the selected shapes from bottom to top. Give each plate a **Plate name** and a **Thickness**, and move it up or down with **Move up one layer** / **Move down one layer**.
4. **Create**.

The shapes stay editable. The [3D view](../features/construction-3d.md#3d-view) shows them stacked flush, with engravings and the [material look](../features/construction-3d.md#material-look) of their layer, which makes it easy to judge depth before cutting.

To change the order or thicknesses later, select the plates and start **Multi-layer work** again.

## Tips

- Give each plate its own colour layer if the plates are different materials or colours, so the 3D view shows them correctly.
- Keep a common outer frame on every plate so the stack lines up when glued.
- Thin sheets (1 to 3 mm) give a fine relief; use more plates rather than thicker ones.
