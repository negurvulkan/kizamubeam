# Tutorials

Each tutorial is a complete project, from the first click to the finished part. They build on [Your first project](../getting-started/first-project.md), which shows the basic workflow: draw, assign layers, set speed and power, preview, frame and start.

| Tutorial | You learn | Time |
|---|---|---|
| [A box with an engraved lid](finger-box.md) | Box generator, fit calibration, engraving on a panel, 3D view | about 45 minutes |
| [Name tags from a list](name-tags-from-a-list.md) | Templates, parameters, series from a table | about 20 minutes |
| [Engraving a photo on wood](photo-engraving.md) | Image modes, adjusting images, material test for engraving | about 30 minutes |
| [A layered shadowbox](shadowbox.md) | Library motifs, Boolean operations, multi-layer work | about 60 minutes |

The times are for working in KizamuBeam; lasering depends on your machine and material.

Want to write a tutorial? Projects you have made with KizamuBeam are a great starting point. See [Contributing to the manual](../contributing.md), or share your idea on [Discord](https://discord.gg/SSr8VHh7EJ).
