# Scorciatoie da tastiera

Su macOS usa **⌘ Cmd** ovunque sia scritto **Ctrl**. Nell’app, **F1** (Aiuto → Scorciatoie da tastiera) mostra le scorciatoie più importanti, e i menu le mostrano accanto a ogni voce.

## File e modifica

| Scorciatoia | Azione |
|---|---|
| Ctrl+N | Nuovo progetto (nuova scheda) |
| Ctrl+O | Apri |
| Ctrl+S | Salva |
| Ctrl+I | Importa (immagini, SVG, DXF, PDF, AI, modelli 3D); i file si possono anche trascinare sull’area di lavoro o incollare con Ctrl+V |
| Ctrl+Z | Annulla |
| Ctrl+Y o Ctrl+Maiusc+Z | Ripeti |
| Ctrl+X / Ctrl+C / Ctrl+V | Taglia / copia / incolla |
| Ctrl+D | Duplica |
| Canc | Elimina |
| Ctrl+A | Seleziona tutto |
| Ctrl+Tab / Ctrl+Maiusc+Tab | Scheda progetto successiva / precedente |
| Pag ↑ / Pag ↓ | Pagina precedente / successiva |

## Strumenti

| Scorciatoia | Azione |
|---|---|
| Esc | Strumento di selezione / annulla la selezione |
| Ctrl+L | Disegna linee |
| Ctrl+R | Rettangolo |
| Ctrl+E | Ellisse |
| Ctrl+T | Testo |
| Ctrl+` | Modifica nodi |
| Ctrl+K | Ritaglia forme |
| Alt+T | Ricalca immagine |
| Alt+P | Anteprima con stima del tempo |

## Disposizione

| Scorciatoia | Azione |
|---|---|
| Tasti freccia | Sposta di 1 mm (Maiusc 10 mm, Alt 0,1 mm) |
| `.` e `,` | Ruota di 90° |
| Ctrl+G / Ctrl+U | Raggruppa / separa |
| Ctrl+Maiusc+H / Ctrl+Maiusc+V | Specchia in orizzontale / in verticale |
| L, R, T, B | Allinea a sinistra, destra, in alto, in basso (più oggetti selezionati) |
| C, E | Allinea i centri in orizzontale, in verticale |
| Alt++ / Alt+- / Alt+* | Unione / differenza / intersezione |
| Alt+J | Unisci percorsi |
| Alt+B | Separa |
| Ctrl+Maiusc+C | Converti in percorso |
| Ctrl+Maiusc+A | Array a griglia |

## Modifica dei nodi

| Scorciatoia | Azione |
|---|---|
| D o Canc | Elimina nodo |
| I | Inserisci nodo |
| L / C | Trasforma il segmento in linea / curva |
| E / S | Trasforma il nodo in angolo / liscio |
| B | Spezza il percorso nel nodo |
| T | Accorcia il lato fino alle intersezioni |

## Vista e mouse

| Scorciatoia | Azione |
|---|---|
| Rotellina del mouse | Zoom |
| Barra spaziatrice + trascinamento, tasto centrale | Sposta la vista |
| Ctrl+0 | Zoom sulla pagina |
| Alt+W | Reticolo / riempito |
| Clic sulla selezione | Passa da ridimensionamento a rotazione |
| Maiusc durante il ridimensionamento | Passa tra proporzionale e libero |
| Ctrl durante il ridimensionamento | Ridimensiona dal centro |
| Maiusc / Ctrl durante la rotazione | Ruota a passi di 15° / 5° |
| Ctrl durante il trascinamento | Inverte temporaneamente l’aggancio |
| Alt durante il trascinamento | Aggancio più forte e guide di allineamento sugli altri oggetti |
| Trascina da un righello | Crea una guida |
