# Sfera a dischi

La **Sfera a dischi** (**Casella degli strumenti → Modelli 3D a incastro**) costruisce una sfera o un paralume con dischi rotondi. I dischi si tengono a vicenda con asole oblique, senza colla.

I dischi stanno sulle direzioni delle facce di un poliedro, scelto in **Layout**. Più dischi danno una sfera più rotonda con più asole; il valore predefinito è l’icosaedro.

| Poliedro | Dischi |
|---|---|
| Cubo | 6 |
| Ottaedro | 8 |
| Dodecaedro | 12 |
| Cuboctaedro | 14 |
| Icosaedro | 20 |
| Rombicubottaedro | 26 |
| Pallone da calcio | 32 |

| Campo | Significato |
|---|---|
| **Diametro** | Diametro esterno della sfera finita. |
| **Sovrapposizione (%)** | 0 % = i dischi si incastrano appena, 100 % = il più possibile senza che tre dischi si incontrino in un punto. Più sovrapposizione dà dischi più grandi, una tenuta più salda e più motivo. |
| **Spessore del materiale** | Spessore del materiale. |
| **Apertura superiore** | Foro nel disco superiore, per esempio per un portalampada (E14 circa 30 mm, E27 circa 40 mm); 0 = nessuno. |
| **Apertura inferiore** | Foro nel disco inferiore, per esempio per cambiare la lampadina (Avanzate). |
| **Gioco di accoppiamento** | Larghezza in più delle asole; negativo = accoppiamento a pressione. |
| **Kerf** | Larghezza del taglio laser. |

Ogni coppia di dischi che si incrociano condivide una corda, che viene divisa a metà: un disco viene inciso da un’estremità, l’altro dall’altra. Le asole per dischi che si incrociano in obliquo diventano più larghe di conseguenza, e gli angoli acuti all’ingresso delle asole ricevono un piccolo smusso.

## Materiale e montaggio

Il materiale sottile e un po’ flessibile funziona meglio: carta, cartoncino, polipropilene o impiallacciatura. I dischi devono piegarsi un po’ quando si inseriscono gli ultimi. Comincia con i dischi attorno a un punto e procedi tutto intorno alla sfera.

Per una lampada usa solo lampadine LED: restano fredde. Tieni carta e legno ben lontani dalla lampadina.

La vista 3D mostra la sfera montata e controlla che i dischi non si compenetrino.
