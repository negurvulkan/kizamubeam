# Tastenkürzel

Auf dem Mac nimmst du **⌘ Cmd** überall dort, wo **Ctrl** steht. In der App zeigt **F1** (Hilfe → Tastenkürzel) die wichtigsten Kürzel, und die Menüs zeigen sie neben jedem Eintrag.

## Dateien und Bearbeiten

| Kürzel | Aktion |
|---|---|
| Ctrl+N | Neues Projekt (neuer Tab) |
| Ctrl+O | Öffnen |
| Ctrl+S | Speichern |
| Ctrl+I | Importieren (Bilder, SVG, DXF, PDF, AI, 3D-Modelle); Dateien auch auf die Arbeitsfläche ziehen oder mit Ctrl+V einfügen |
| Ctrl+Z | Rückgängig |
| Ctrl+Y oder Ctrl+Shift+Z | Wiederholen |
| Ctrl+X / Ctrl+C / Ctrl+V | Ausschneiden / Kopieren / Einfügen |
| Ctrl+D | Duplizieren |
| Entf | Löschen |
| Ctrl+A | Alles auswählen |
| Ctrl+Tab / Ctrl+Shift+Tab | Nächster / vorheriger Projekt-Tab |
| Bild ↑ / Bild ↓ | Vorherige / nächste Seite |

## Werkzeuge

| Kürzel | Aktion |
|---|---|
| Esc | Auswahlwerkzeug / Auswahl aufheben |
| Ctrl+L | Linien zeichnen |
| Ctrl+R | Rechteck |
| Ctrl+E | Ellipse |
| Ctrl+T | Text |
| Ctrl+` | Knoten bearbeiten |
| Ctrl+K | Formen trimmen |
| Alt+T | Bild nachzeichnen |
| Alt+P | Vorschau mit Zeitschätzung |

## Anordnen

| Kürzel | Aktion |
|---|---|
| Pfeiltasten | 1 mm verschieben (Shift 10 mm, Alt 0,1 mm) |
| `.` und `,` | Um 90° drehen |
| Ctrl+G / Ctrl+U | Gruppieren / Gruppierung aufheben |
| Ctrl+Shift+H / Ctrl+Shift+V | Horizontal / vertikal spiegeln |
| L, R, T, B | Links, rechts, oben, unten ausrichten (mehrere Objekte gewählt) |
| C, E | Mitten waagerecht, senkrecht ausrichten |
| Alt++ / Alt+- / Alt+* | Vereinen / Abziehen / Schnittmenge |
| Alt+J | Pfade verbinden |
| Alt+B | Zerlegen |
| Ctrl+Shift+C | In Pfad umwandeln |
| Ctrl+Shift+A | Rasterarray |

## Knoten bearbeiten

| Kürzel | Aktion |
|---|---|
| D oder Entf | Knoten löschen |
| I | Knoten einfügen |
| L / C | Segment zur Geraden / Kurve machen |
| E / S | Knoten zur Ecke / glatt machen |
| B | Pfad am Knoten auftrennen |
| T | Kante bis zu den Schnittpunkten zurückschneiden |

## Ansicht und Maus

| Kürzel | Aktion |
|---|---|
| Mausrad | Zoomen |
| Leertaste + Ziehen, mittlere Maustaste | Ansicht verschieben |
| Ctrl+0 | Ganze Seite |
| Alt+W | Drahtgitter / gefüllt |
| Klick auf die Auswahl | Zwischen Skalieren und Drehen wechseln |
| Shift beim Skalieren | Zwischen proportional und frei wechseln |
| Ctrl beim Skalieren | Von der Mitte aus skalieren |
| Shift / Ctrl beim Drehen | In 15°- / 5°-Schritten drehen |
| Ctrl beim Ziehen | Fangen vorübergehend umkehren |
| Alt beim Ziehen | Stärker fangen und Ausrichtungshilfen an anderen Objekten |
| Aus einem Lineal ziehen | Hilfslinie anlegen |
