# Scheibenkugel

Die **Scheibenkugel** (**Werkzeugkasten → 3D-Steckmodelle**) baut eine Kugel oder einen Lampenschirm aus runden Scheiben. Die Scheiben halten sich über schräge Schlitze gegenseitig, ohne Leim.

Die Scheiben sitzen auf den Flächenrichtungen eines Polyeders, gewählt unter **Anordnung**. Mehr Scheiben ergeben eine rundere Kugel mit mehr Schlitzen; Standard ist das Ikosaeder.

| Polyeder | Scheiben |
|---|---|
| Würfel | 6 |
| Oktaeder | 8 |
| Dodekaeder | 12 |
| Kuboktaeder | 14 |
| Ikosaeder | 20 |
| Rhombenkuboktaeder | 26 |
| Fußball | 32 |

| Feld | Bedeutung |
|---|---|
| **Durchmesser** | Außendurchmesser der fertigen Kugel. |
| **Überlappung (%)** | 0 % = die Scheiben greifen gerade ineinander, 100 % = so weit wie möglich, ohne dass sich drei Scheiben in einem Punkt treffen. Mehr Überlappung ergibt größere Scheiben, festeren Halt und mehr Muster. |
| **Materialdicke** | Dicke des Materials. |
| **Öffnung oben** | Loch in der oberen Scheibe, etwa für eine Lampenfassung (E14 etwa 30 mm, E27 etwa 40 mm); 0 = keines. |
| **Öffnung unten** | Loch in der unteren Scheibe, etwa zum Wechseln der Lampe (Erweitert). |
| **Steckspiel** | Zusätzliche Schlitzbreite; negativ = Presspassung. |
| **Schnittfuge (Kerf)** | Breite des Laserschnitts. |

Jedes Paar sich kreuzender Scheiben teilt sich eine Sehne, die halbiert wird: Eine Scheibe wird vom einen Ende her geschlitzt, die andere vom anderen. Schlitze für Scheiben, die sich schräg kreuzen, werden entsprechend breiter, und spitze Ecken an den Schlitzeingängen bekommen eine kleine Fase.

## Material und Zusammenbau

Dünnes, etwas biegsames Material funktioniert am besten: Papier, Karton, Polypropylen oder Furnier. Die Scheiben müssen sich ein wenig biegen, wenn die letzten eingesteckt werden. Beginne mit den Scheiben um einen Punkt herum und arbeite dich um die Kugel herum.

Für eine Lampe nur LED-Leuchtmittel verwenden: Sie bleiben kühl. Halte Papier und Holz gut vom Leuchtmittel fern.

Die 3D-Ansicht zeigt die zusammengesetzte Kugel und prüft, dass sich die Scheiben nicht durchdringen.
