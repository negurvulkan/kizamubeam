# Schubladen, Einsätze und Regale

Diese Generatoren bauen auf der Box mit Fingerzinken auf und stehen unter **Werkzeugkasten → Boxen und Möbel**. Alle sind Baugruppen: Die [3D-Ansicht](../features/construction-3d.md#3d-view) zeigt sie zusammengebaut, und die Tests dahinter prüfen, dass sich keine Teile überlappen.

## Schublade

Eine Schublade mit vorn offenem Korpus, passendem Schubkasten und Blende. Ohne Korpus bekommst du nur den Schubkasten, für eine schon vorhandene Öffnung.

| Feld | Bedeutung |
|---|---|
| **Breite**, **Höhe**, **Tiefe** | Außenmaß des Korpus. Ohne Korpus: Größe der Öffnung. |
| **Materialdicke** | Dicke der Platte. |
| **Mit Korpus** | Baut den Korpus mit. |
| **Blende** | **Vorgesetzt (deckt den Korpus ab)**, **Eingelegt (in der Öffnung)** oder **Keine**. |
| **Griff** | **Griffloch (Langloch)** oder **Rundes Loch**, mit **Griffbreite** (Länge des Langlochs oder Lochdurchmesser) und **Griffhöhe**; oder **Keiner**. |
| **Luft seitlich**, **Luft oben**, **Luft hinten** | Luft zwischen Schubkasten und Korpus. |
| **Fuge um die Blende** | Die Blende wird an jeder Seite um so viel kleiner. |
| **Schnittfuge (Kerf)** | Breite des Laserschnitts. |

**Zinkenbreite** und **Steckspiel** stehen unter **Erweitert**.

## Einsatz mit Fächern

Ein Gitter aus halb eingeschnittenen Stegen, die ineinandergesteckt werden, für eine Box oder Schublade: für Schrauben, Perlen, Teebeutel oder Spielfiguren.

| Feld | Bedeutung |
|---|---|
| **Innenbreite** / **Innentiefe** | Innenmaß der Box oder Schublade, in die der Einsatz kommt. |
| **Höhe der Stege** | Höhe der Trennstege. |
| **Materialdicke** | Dicke der Platte. |
| **Fächer in der Breite** / **Fächer in der Tiefe** | Anzahl der Fächer in jeder Richtung. |
| **Steckspiel** | Schlitze werden um so viel breiter als die Materialdicke; negativ = Presspassung. |
| **Endluft** | Die Stege werden um so viel kürzer als das Innenmaß, damit der Einsatz leicht hineinfällt. |
| **Schnittfuge (Kerf)** | Breite des Laserschnitts. |

## Steckregal

Zwei Seiten und beliebig viele Böden, verbunden über Kreuzschlitze: kein Leim, keine Schrauben.

| Feld | Bedeutung |
|---|---|
| **Breite** | Länge der Böden. |
| **Tiefe**, **Höhe** | Größe der Seiten. |
| **Materialdicke** | Dicke der Platte. Ab 4 mm wird das Regal stabil. |
| **Anzahl Böden** | 1 bis 30. |
| **Unterster Boden über Grund** | Höhe der Unterseite des untersten Bodens. |
| **Oberster Boden unter Oberkante** | Abstand von der Oberkante der Seiten bis zur Oberseite des obersten Bodens. |
| **Überstand der Böden** | Wie weit die Böden über die Seiten hinausragen. |
| **Steckspiel** | Zusätzliche Schlitzbreite; negativ = Presspassung. |
| **Schnittfuge (Kerf)** | Breite des Laserschnitts. |

Die Böden werden gleichmäßig zwischen dem untersten und dem obersten verteilt.
