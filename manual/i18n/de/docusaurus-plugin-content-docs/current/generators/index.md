# Generatoren

Generatoren erzeugen fertige Teile aus wenigen Maßen, statt sie von Hand zu zeichnen. Alle stehen im **Werkzeugkasten** (der Kachelknopf in der Werkzeugleiste oder **Fenster → Werkzeugkasten**), nach Gruppen sortiert und durchsuchbar.

Die meisten Generatoren erzeugen **parametrische Teile**: Sie behalten ihre Parameter im Projekt. Ein Doppelklick auf ein Teil öffnet es später wieder, und alles wird neu berechnet. Die Felder verstehen Projektparameter und Formeln, so kann eine Box etwa der Materialstärke einer Vorlage folgen.

| Generator | Was er erzeugt |
|---|---|
| Stirnrad und Zahnradpaar | Evolventenzahnräder; ein Paar greift im richtigen Achsabstand und dreht sich in der 3D-Ansicht |
| Zahnstange | Gerade Zahnstange passend zum Stirnrad |
| Zahnriemenscheibe | Scheiben für GT2- und HTD-Riemen |
| Kurvenscheibe | Nocken mit Hub, Rast und Rückhub für Rollen- oder Schneidenstößel |
| Box mit Fingerzinken | Offene oder geschlossene Box mit Fingerzinken, Schnittbreite und Passungsspiel |
| Schublade | Korpus, Schubkasten und Front, oder nur ein Schubkasten für eine vorhandene Öffnung |
| Einsatz mit Fächern | Ein Gitter aus halb eingeschlitzten Trennwänden für Box oder Schublade |
| Steckregal | Seiten und Böden mit Kreuzschlitzen, ohne Leim und Schrauben |
| Deckelscharnier | Scharnierknöchel mit Stift, die einen Deckel mit der Box verbinden |
| Biegeschnitte | Schnittmuster, die eine Platte biegsam machen |
| Scheibenkugel | Eine Kugel oder ein Lampenschirm aus ineinandergesteckten Scheiben |
| Schicht- und Rippenmodelle | Gestapelte oder gesteckte Platten aus einem 3D-Modell (STL/OBJ) |

Die [vollständige Funktionsliste](https://github.com/negurvulkan/kizamubeam/blob/main/docs/features.de.md#verbindungen-generatoren-und-3d) beschreibt jeden Parameter. Eine eigene Referenzseite mit Beispielen für jeden Generator folgt hier.
