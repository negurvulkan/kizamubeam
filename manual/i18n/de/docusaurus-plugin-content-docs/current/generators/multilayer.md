# Mehrlagenarbeit

**Mehrlagenarbeit** (**Werkzeugkasten → 3D-Steckmodelle**) macht aus selbst gestalteten Formen ein gestapeltes Stück: eine Shadowbox, eine geschichtete Landschaft, ein Relief oder ein Schild mit mehreren Ebenen. Anders als beim [Schichtmodell](models-3d.md) kommen die Lagen aus deiner eigenen Zeichnung, nicht aus einer 3D-Datei.

## Erstellen

1. Zeichne jede Lage als geschlossene Form oder Gruppe (etwa Rahmen, Berge, Bäume, Himmel).
2. Wähle alle aus und wähle **Mehrlagenarbeit** im Werkzeugkasten.
3. Der Dialog listet die ausgewählten Formen von unten nach oben. Gib jeder Platte einen **Name der Platte** und eine **Dicke** und verschiebe sie mit **Eine Ebene höher** / **Eine Ebene tiefer**.
4. **Erstellen**.

Die Formen bleiben bearbeitbar. Die [3D-Ansicht](../features/construction-3d.md#3d-view) zeigt sie bündig gestapelt, mit Gravuren und dem [Materialaussehen](../features/construction-3d.md#material-look) ihres Layers, so lässt sich die Tiefenwirkung vor dem Schneiden gut beurteilen.

Um Reihenfolge oder Dicken später zu ändern, wähle die Platten aus und starte **Mehrlagenarbeit** erneut.

## Tipps

- Gib jeder Platte einen eigenen Farb-Layer, wenn die Platten aus verschiedenen Materialien oder Farben sind, damit die 3D-Ansicht sie richtig zeigt.
- Behalte auf jeder Platte einen gemeinsamen Außenrahmen, damit der Stapel beim Verleimen bündig liegt.
- Dünne Platten (1 bis 3 mm) ergeben ein feines Relief; nimm lieber mehr Platten als dickere.
