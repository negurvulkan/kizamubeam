# Tutorials

Jedes Tutorial ist ein vollständiges Projekt, vom ersten Klick bis zum fertigen Teil. Sie bauen auf [Dein erstes Projekt](../getting-started/first-project.md) auf, das den Grundablauf zeigt: zeichnen, Layer zuweisen, Geschwindigkeit und Leistung einstellen, Vorschau, Rahmen und Start.

| Tutorial | Du lernst | Dauer |
|---|---|---|
| [Eine Box mit graviertem Deckel](finger-box.md) | Box-Generator, Passungs-Kalibrierung, Gravur auf einer Wand, 3D-Ansicht | etwa 45 Minuten |
| [Namensschilder aus einer Liste](name-tags-from-a-list.md) | Vorlagen, Parameter, Serie aus einer Tabelle | etwa 20 Minuten |
| [Ein Foto auf Holz gravieren](photo-engraving.md) | Bildmodi, Bilder anpassen, Materialtest für Gravuren | etwa 30 Minuten |
| [Eine Shadowbox aus Schichten](shadowbox.md) | Motive aus der Bibliothek, boolesche Operationen, Mehrlagenarbeit | etwa 60 Minuten |

Die Zeiten gelten für die Arbeit in KizamuBeam; wie lange das Lasern dauert, hängt von Maschine und Material ab.

Du möchtest ein Tutorial schreiben? Projekte, die du mit KizamuBeam gemacht hast, sind ein guter Ausgangspunkt. Siehe [Am Handbuch mitarbeiten](../contributing.md), oder teile deine Idee auf [Discord](https://discord.gg/SSr8VHh7EJ).
