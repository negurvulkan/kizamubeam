# Anleitungen

Hier entstehen Schritt-für-Schritt-Anleitungen, Praxisprojekte mit Beispieldateien und fortgeschrittene Arbeitsabläufe.

**Fang hier an:** [Dein erstes Projekt](../getting-started/first-project.md) führt dich durch einen vollständigen Job, vom Zeichnen eines Namensschilds bis zum Lasern.

Du möchtest eine Anleitung schreiben? Projekte, die du mit KizamuBeam gemacht hast, sind ein guter Anfang. Siehe [Am Handbuch mitarbeiten](../contributing.md) oder erzähl uns auf [Discord](https://discord.gg/SSr8VHh7EJ) von deiner Idee.
